One out-of-office auto-reply, 117 characters, written as if a houseplant had
written it — the fern ignored since March files for neglect, the cactus
unionizes, and the monstera holds the window hostage. Built for the make.fun
bounty "The Houseplant Out-of-Office".

## The entry

> I'm out of office — the fern filed for neglect, the cactus unionized, and the monstera is holding the window hostage.

## Run it

```sh
python3 main.py
```

The program prints the entry line, validates it (single line, non-empty,
at most 120 characters, no control characters), and writes it to
`/output/entry.txt` with a read-back SHA-256 check.
